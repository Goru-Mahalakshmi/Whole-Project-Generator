# Whole Project Generator

An AI-powered platform designed to simplify project creation and GitHub repository analysis.

## Features

- AI-powered project generation
- GitHub repository analysis
- Modern user interface
- Theme toggling
- Developer-friendly workflow

## Tech Stack

- React
- TypeScript
- Node.js
- Express
- Tailwind CSS

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Goru-Mahalakshmi/Whole-Project-Generator.git
cd Whole-Project-Generator
```

Install dependencies:

```bash
npm install
```

Start the development server using the appropriate script in `package.json`.
